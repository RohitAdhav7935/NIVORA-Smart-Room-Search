# 🏠 NIVORA – Smart Room Search & Analytics Platform

**NIVORA** is a simple web-based platform designed to help people find available rooms and rental properties in their preferred area.

The main idea behind NIVORA is to make the room-search process easier by bringing property information into one place. Property owners can submit their room or property details through a simple online form. The collected information is stored in Google Sheets and can then be used by the NIVORA web application.

Tenants can search for available rooms based on their preferred location and view important property details such as room type, monthly rent, facilities, availability and other information provided by the owner.

The project also includes a **Looker Studio analytics dashboard**. This dashboard helps us understand the collected property data through charts and visual reports. For example, we can analyze the number of available rooms, properties in different areas, rental prices, room types and available facilities.

NIVORA combines **data collection, data storage, web application development and data analytics** into one simple project.

---

## 🎯 Project Objective

The main objective of NIVORA is to create a simple and useful platform for collecting, managing, searching and analyzing room and rental property information.

The project focuses on the following objectives:

* 📝 **Collect Property Information**
  Provide an easy way for property owners to submit their room or property details.

* 📊 **Store Data in a Structured Way**
  Store all submitted property information in Google Sheets so that the data can be easily managed and analyzed.

* 🔎 **Make Room Searching Easier**
  Allow tenants to search for available rooms based on their preferred area or location.

* 🏠 **Display Property Details**
  Show important information such as room type, monthly rent, security deposit, facilities, availability and description.

* 📍 **Location-Based Search**
  Help users find rooms according to different areas and locations.

* 📈 **Analyze Property Data**
  Use Looker Studio to create dashboards and understand patterns in the collected data.

* 🔄 **Create an End-to-End Data Workflow**
  Connect data collection, data storage, web application and analytics into one workflow.

* 💡 **Provide a Simple User Experience**
  Keep the application simple so that both property owners and tenants can use it easily.

## 🔄 How NIVORA Works

The project follows a simple data flow:

```text
Property Owner
      ↓
Google Form
      ↓
Google Sheets
      ↓
Google Apps Script
      ↓
NIVORA Web Application
      ↓
Tenant Searches Rooms
```

The same property data is also connected to the analytics system:

```text
Google Sheets
      ↓
Looker Studio
      ↓
Analytics Dashboard
```

This creates a complete workflow from **data collection to data analysis**.

## 🛠️ Technology Used

NIVORA uses Google-based tools and web technologies to build the complete project.

* **Google Forms** – Used to collect property information from owners.
* **Google Sheets** – Used to store and manage the collected data.
* **Google Apps Script** – Used to connect the data with the web application and handle application logic.
* **HTML** – Used to create the structure of the web interface.
* **CSS** – Used to design and improve the appearance of the application.
* **JavaScript** – Used to add search functionality and interactive features.
* **Looker Studio** – Used to create the analytics dashboard and visualize the collected data.

## 💡 Why We Created NIVORA

Finding a suitable room can take time because property information may be available in different places and formats.

NIVORA was created as a simple solution to organize this information in one system.
